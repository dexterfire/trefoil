# Локализация

Trefoil — русскоязычный продукт по умолчанию. Английский — вторая локаль. Правила простые и обязательные.

## Где живут строки

- `app/src/main/res/values/strings.xml` — **русский текст**, он же язык по умолчанию (и то, что видит продукт).
- `app/src/main/res/values-en/strings.xml` — английский перевод тех же ключей.
- Файлы строк, разделённые по владельцам (`strings_dev_servers_pane.xml`, `widget_limits_strings.xml`,
  `widget_usage_strings.xml`), зеркалятся в обоих каталогах: русский в `values/`, английский в `values-en/`.

## Правила

1. **Ни одного пользовательского литерала в `app/src/main/kotlin`.** Новый UI-текст добавляется как
   `<string name="…">` в `values/strings.xml` + перевод в `values-en/strings.xml`, а в Compose читается
   `stringResource(R.string.…)` (с аргументами — `%1$s`, `%2$d` и `stringResource(id, args…)`).
   Guard-тест `UiStringLiteralGuardTest` (`app/src/test/.../UiStringLiteralGuardTest.kt`) сканирует
   исходники и падает на новые кавычечные литералы в UI-слоях; допуск — только через whitelist в файле
   `app/src/test/resources/ui-string-literal-allowlist.txt` (пути + литералы, по одному на строку).
   Нелитеральные строки из протокола/сервера (заголовки тредов, имена проектов, ошибки провайдеров) —
   не UI-текст и под тест не подпадают.
2. **Подписи для скринридера и tooltip'ы — тоже UI-текст.** `contentDescription`, `onClickLabel`,
   `stateDescription`, тултипы — идут через ресурсы наравне с видимым текстом.
3. **Только пунктуация (`" · "`, `"…"`, `"—"`) и технические константы (ключи, теги, пути, regex'ы)
   остаются литералами** — они не переводимы; если тест на них ругается, добавьте в whitelist с комментарием.
4. **Терминология T3 согласована везде** (один и тот же перевод во всех экранах):

   | T3-термин | Русский |
   |---|---|
   | working | Работает |
   | waiting | Ожидает |
   | queued | В очереди |
   | settled | Завершён |
   | snoozed | Отложен |
   | pinned | Закреплён |
   | archived | В архиве |
   | drafts | Черновики |
   | turn | ход |
   | thread | тред |
   | machine | машина |
   | dev server | dev-сервер |
   | port forward | проброс порта |

5. **Скриншот-эталоны.** Превью рендерятся в локали тестовой JVM (en-US, поэтому строки берутся из
   `values-en/`), а не в русской: русский текст в `values/` эталоны не меняет, английский текст в
   `values-en/` и видимые правки экранов меняют — см. `docs/SCREENSHOT_TESTING.md` про узкий
   перебейзлайн (`--tests` по затронутым файлам).
6. **Per-app language (Android 13+).** Включён через `android:localeConfig="@xml/locales_config"`
   (`res/xml/locales_config.xml`: `ru`, `en`). Поддерживаемые локали не фильтруются сборкой —
   язык выбирается системой из этого списка.
7. **Строки сервера и протокола не локализуем.** Заголовки тредов, имена проектов, тексты ошибок
   провайдеров приходят с T3-сервера — их не переводим и в ресурсы не переносим.
